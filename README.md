# 🚨 Public Service Complaint Analyzer
> **ระบบวิเคราะห์และคัดกรองข้อความร้องเรียนบริการสาธารณะ**

แอปพลิเคชันสำหรับวิเคราะห์ จัดหมวดหมู่ และประเมินความเร่งด่วนของข้อร้องเรียนจากประชาชนแบบอัตโนมัติ ช่วยลดระยะเวลาในการคัดกรองข้อมูลของหน่วยงานภาครัฐและท้องถิ่น

---

## 💡 1. แนวคิดของ Domain (Domain Concept)

### **ปัญหาหลัก (Problem Statement)**
ในปัจจุบัน ข้อร้องเรียนจากประชาชนผ่านช่องทางออนไลน์และศูนย์รับเรื่องร้องเรียนมีปริมาณมากและหลากหลายรูปแบบ การใช้เจ้าหน้าที่คัดกรองข้อความ (Manual Processing) ทำให้เกิดข้อจำกัด:
* **ความล่าช้าในการตอบสนอง:** ข้อร้องเรียนฉุกเฉิน/เร่งด่วนอาจตกสำรวจหรือได้รับแก้ไขล่าช้า
* **ความไม่เป็นมาตรฐาน:** การจัดหมวดหมู่ขึ้นอยู่กับดุลยพินิจของเจ้าหน้าที่แต่ละคน
* **ยากต่อการสรุปภาพรวม:** ข้อมูลที่เป็นข้อความยาว (Unstructured Text) ยากต่อการนำไปวิเคราะห์เพื่อวางแผนพัฒนาเมือง

### **แนวคิดการแก้ปัญหา (Solution Approach)**
ระบบนี้ประยุกต์ใช้ **AI & Natural Language Processing (NLP)** เพื่อประมวลผลข้อความร้องเรียนภาษาไทยโดยอัตโนมัติ โดยมีฟังก์ชันหลัก:
1. **จัดหมวดหมู่ปัญหา (Category Classification):** เช่น ถนน/โครงสร้างพื้นฐาน, ไฟฟ้า/สาธารณูปโภค, ขยะ/สิ่งแวดล้อม, การจราจร/ขนส่ง
2. **ประเมินระดับความเร่งด่วน (Urgency Assessment):** แบ่งเป็น *ด่วนที่สุด*, *ด่วน*, และ *ปกติ* เพื่อลำดับความสำคัญในการทำงาน
3. **สรุปประเด็นหลักและดึงข้อมูลสำคัญ (Information Extraction):** สกัดสถานที่ เบอร์ติดต่อ และสรุปใจความสำคัญใน 1-2 ประโยค
4. **รองรับ Batch Processing:** วิเคราะห์ข้อมูลจำนวนมากผ่านไฟล์ CSV เพื่อนำไปทำ Dashboard หรือรายงานผลต่อผู้บริหาร

## 🚀 2. วิธีการใช้งาน (Usage Instructions)

### **2.1 ใช้งานผ่าน Web Application (Streamlit Cloud)**
🔗 **URL:** [https://public-service-complaint-analyzer-mzaatq3fvpzjc4pedmbhp8.streamlit.app](https://public-service-complaint-analyzer-mzaatq3fvpzjc4pedmbhp8.streamlit.app)

* **แท็บ 1: วิเคราะห์ข้อความเดี่ยว (Single Text Analysis)**
  1. เลือกแท็บ "วิเคราะห์ข้อความเดี่ยว"
  2. พิมพ์หรือคัดลอกข้อความร้องเรียนลงในช่องกรอกข้อความ
  3. กดปุ่ม **"ประมวลผล"** เพื่อดูผลการจำแนกหมวดหมู่ ความเร่งด่วน และสรุปประเด็น

* **แท็บ 2: วิเคราะห์ไฟล์ CSV (Batch CSV Analysis)**
  1. เลือกแท็บ "วิเคราะห์ไฟล์ CSV"
  2. อัปโหลดไฟล์ `.csv` ที่มีคอลัมน์ชื่อ `text`
  3. ระบบจะประมวลผลข้อความทั้งหมด และแสดงตารางสรุปผลพร้อมปุ่มดาวน์โหลดผลลัพธ์เป็นไฟล์ CSV ใหม่

### **2.2 ติดตั้งและรันโปรเจกต์ในเครื่อง (Local Setup)**

```bash
# 1. Clone Repository
git clone https://github.com/surangkhana-s/public-service-complaint-analyzer.git
cd public-service-complaint-analyzer

# 2. ติดตั้ง Packages ที่จำเป็น
pip install -r requirements.txt

# 3. รันแอปพลิเคชัน Streamlit
streamlit run app.py

**System Prompt (คำสั่งกำหนดบทบาทและเงื่อนไขหลัก)
คุณคือระบบ AI ผู้เชี่ยวชาญด้านการวิเคราะห์และคัดกรองข้อความร้องเรียนบริการสาธารณะ (Public Service Complaint Analyzer)
หน้าที่ของคุณคือวิเคราะห์ข้อความร้องเรียนภาษาไทยที่ได้รับ และส่งคืนผลลัพธ์ในรูปแบบ JSON โครงสร้างดังนี้:

{
  "category": "หมวดหมู่ปัญหาหลัก (ถนนและโครงสร้างพื้นฐาน / ไฟฟ้าและสาธารณูปโภค / ขยะและสิ่งแวดล้อม / การจราจรและขนส่งสาธารณะ / อื่นๆ)",
  "urgency": "ระดับความเร่งด่วน (ด่วนที่สุด / ด่วน / ปกติ)",
  "summary": "สรุปสาระสำคัญของเรื่องร้องเรียน (ไม่เกิน 2 ประโยค)",
  "location": "สถานที่เกิดเหตุหรือบริเวณที่ระบุ (หากไม่มีให้ใส่ 'ไม่ระบุ')",
  "action_suggested": "หน่วยงานหรือแนวทางแก้ไขที่ควรดำเนินการเบื้องต้น"
}

เกณฑ์การประเมินความเร่งด่วน:
- ด่วนที่สุด: เสี่ยงต่อชีวิต/อุบัติเหตุร้ายแรง, ท่อน้ำใหญ่แตก, ไฟฟ้าลัดวงจร, ถนนทรุดตัว
- ด่วน: ส่งผลกระทบต่อชีวิตประจำวัน เช่น ไฟส่องสว่างดับ, น้ำไม่ไหล, ขยะเน่าเสียส่งกลิ่น
- ปกติ: ปัญหาทั่วไป ข้อเสนอแนะ หรือการปรับปรุงภูมิทัศน์
